# Situación de licencia

## Importante

NRMenu contiene archivos derivados de ALTRA64/alt64. La rama de `ariahiro64/altra64` utilizada como base se presenta públicamente como un proyecto open source, pero al preparar NRMenu v1.0 no se encontró un archivo `LICENSE`, `COPYING` o equivalente en la raíz de ese repositorio.

Por lo tanto:

1. Este repositorio **no intenta relicenciar** el código heredado.
2. Deben conservarse todos los encabezados de copyright, créditos y avisos existentes.
3. La publicación de este código no constituye una afirmación de titularidad exclusiva por parte de NovenRetro.
4. Quien redistribuya, modifique o comercialice un derivado debe revisar la cadena completa de derechos y las licencias de cada dependencia.
5. No se incluye ninguna autorización para distribuir ROMs, BIOS, arte comercial, música, marcas o contenido protegido de terceros.

## Contribuciones nuevas

Hasta que la situación upstream quede aclarada con una licencia explícita, cada colaborador conserva los derechos sobre sus contribuciones nuevas y acepta que sean publicadas dentro de este repositorio para su revisión y uso comunitario, sin modificar los derechos aplicables al código heredado.

Este archivo es una nota de situación y no sustituye asesoramiento jurídico.

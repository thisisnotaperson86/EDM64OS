# Roadmap sugerido

No es un compromiso; son puntos útiles para futuros colaboradores.

## Prioridad alta

- Aclarar y documentar una licencia upstream explícita.
- Automatizar pruebas de rutas, Favoritos e Historial.
- Añadir identificación de carátulas por Game ID completo o CRC.
- Probar sistemáticamente EEPROM 4K/16K, SRAM y FlashRAM.

## Prioridad media

- Configurar demora de carátula desde `ALTRA64.INI`.
- Caché de múltiples carátulas.
- Indicador visual de favorito.
- Limpieza segura de entradas inexistentes.
- Traducción completa inglés/español.

## Investigación

- Migración o port parcial hacia N64FlashcartMenu.
- Mejoras de compatibilidad con juegos problemáticos.
- Soporte de boxart por nombre/CRC sin colisiones.
- Herramientas de diagnóstico de guardados.

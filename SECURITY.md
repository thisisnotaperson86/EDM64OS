# Seguridad y datos

NRMenu se ejecuta en hardware retro y no ofrece servicios de red. El principal riesgo práctico es la pérdida o corrupción de datos en la SD.

Para reportar un problema que pueda destruir partidas o archivos, abrí un issue con el prefijo `[DATA LOSS]` y detallá el procedimiento mínimo para reproducirlo. No adjuntes ROMs ni partidas privadas.
